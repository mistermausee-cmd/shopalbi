# shopalbi — сканер рынка Albion Online

Веб-инструмент, который собирает цены со всех королевских городов и Чёрного
рынка Карлеона (сервер **Europe**), считает средние цены и объёмы за
**день / 3 дня / неделю / месяц** и показывает **самые выгодные вещи для вывоза
на Чёрный рынок** — с прибылью в серебре и процентах, скоростью выкупа и оценкой
надёжности сделки.

Игру запускать **не нужно**. Данные берутся из публичного API
[Albion Online Data Project](https://www.albion-online-data.com) — их собирают
тысячи игроков через официальный клиент, читающий рыночный трафик. Мы только
читаем и анализируем эти данные, что разработчики Albion прямо разрешают.

---

## Что внутри

- **Вкладка «Выгодные флипы»** — топ вещей: где купить дешевле всего, за сколько
  выкупает Чёрный рынок, чистая прибыль (после налога 4% с премиумом) в серебре и
  процентах. Рядом — прибыль по **средней цене ЧР за период** (защита от разового
  скачка), примерная скорость выкупа и **оценка надёжности 0–100**.
- **Вкладка «Средние цены»** — таблица по всем городам: средневзвешенная по объёму
  цена и оборот за выбранный период, плюс подсказка, где предмет дешевле всего.
- Переключатель периода: **День / 3 дня / Неделя / Месяц**.
- Фильтры: тип (оружие/броня/оффхенд/плащ/сумка), тир **T4–T8**, качество, поиск,
  минимальная прибыль. Сортировка по клику на заголовок.

Сканируется вся **боевая экипировка T4–T8** — именно её покупает Чёрный рынок
(оружие, оффхенды, броня, плащи, сумки). Ресурсы, еда и зелья не берутся: ЧР их
не выкупает.

## Математика

Флип «купил в городе → отвёз в Карлеон → продал мгновенно в ордер выкупа ЧР»:

```
Затраты   = цена покупки в городе (самый дешёвый ордер продажи)
Выручка   = цена выкупа ЧР × (1 − налог)     # налог 4% с премиумом
Прибыль   = Выручка − Затраты
Прибыль % = Прибыль / Затраты × 100
```

- **Средние цены** — средневзвешенные по объёму сделок, чтобы пара мелких продаж
  не искажала число.
- **Скорость выкупа** — оценка по дневному обороту ЧР (`24 ч ÷ штук в день`). Это
  приблизительно: игра не отдаёт точное «время», только объёмы.
- **Надёжность (0–100)** — сочетает свежесть цен, ликвидность ЧР и совпадение
  текущей прибыли с недельной. Высокий балл = реальная стабильная сделка, низкий =
  вероятно разовый скачок цены без объёма.

## Запуск на Ubuntu 24.04 (VPS) — одна команда

Нужен установленный Docker. Если его нет:

```bash
curl -fsSL https://get.docker.com | sh
```

Затем в папке проекта:

```bash
docker compose up -d --build
```

Готово. Открой в браузере: `http://АДРЕС_ТВОЕЙ_VPS:8000`

При первом запуске сервер минуту-две подтягивает данные (индикатор вверху станет
зелёным). Дальше цены обновляются каждые 10 минут автоматически. Данные и кэш
хранятся в Docker-томе `shopalbi-data`, так что переживают перезапуск.

Полезные команды:

```bash
docker compose logs -f      # смотреть логи
docker compose restart      # перезапустить
docker compose down         # остановить
```

### Требования к серверу

Хватает самого дешёвого инстанса: **1 vCPU, 1 ГБ RAM**, ~1 ГБ диска. Видеокарта
не нужна. На Azure подойдёт **B1s**.

## Запуск без Docker (для локальной проверки)

Нужен Python 3.10+.

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Настройка

Все параметры задаются переменными окружения (в `docker-compose.yml` или `.env`).
Полный список — в [`.env.example`](.env.example). Часто нужные:

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `SHOPALBI_SALES_TAX` | Налог продажи ЧР (премиум 0.04, без — 0.08) | `0.04` |
| `SHOPALBI_MIN_PROFIT` | Мин. прибыль для показа флипа | `1000` |
| `SHOPALBI_CURRENT_REFRESH_MINUTES` | Как часто обновлять цены | `10` |
| `SHOPALBI_API_HOST` | Регион сервера | EU |
| `SHOPALBI_AUTH_USER` / `SHOPALBI_AUTH_PASS` | Пароль на сайт (если нужен) | пусто (открыт) |

## Как устроено

```
backend/app/
  config.py        параметры (города, налог, расписание, охват)
  catalog.py       каталог предметов: фильтр экипировки ЧР + русские названия
  aodp_client.py   клиент API (батчинг под лимит URL, ограничение частоты, gzip, ретраи)
  storage.py       SQLite (цены, история, каталог)
  engine.py        математика: агрегаты по окнам + расчёт флипов
  scheduler.py     фоновое обновление
  main.py          FastAPI: JSON API + отдача интерфейса
frontend/          статический интерфейс (index.html, app.js, styles.css)
```

API: `/api/status`, `/api/meta`, `/api/stats`, `/api/flips`, `/api/refresh`, `/api/health`.

## Оговорки

- Свежесть данных зависит от того, как часто игроки-сборщики заходили на нужные
  рынки. Редкие предметы могут быть с устаревшими ценами — движок помечает это
  низкой надёжностью и фильтрует по возрасту цены.
- «Скорость выкупа» и прогноз — оценки по историческому обороту, а не гарантия.
- Прибыль считается на **мгновенную** продажу в существующий ордер выкупа ЧР.
